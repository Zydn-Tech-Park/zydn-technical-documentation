# 5. Technical SEO Implementation

Technical SEO ensures that search engines can crawl, render, understand, and index the website effectively.

## 5.1 Title Tags

Each website page should have a unique and descriptive title tag.

Example homepage title:

**ZYDN - Software, Web Development & Technology Park**

Recommendations:
- Keep titles relevant to page content.
- Include primary keywords naturally.
- Avoid duplicate title tags.
- Maintain appropriate title length.

## 5.2 Meta Descriptions

Meta descriptions provide a short summary of webpage content in search results.

Example homepage description:

"ZYDN provides expert software architecture, mobile app development, web design, and research solutions in Marthandam, Tamil Nadu, India."

Recommendations:
- Write unique descriptions for every important page.
- Include relevant keywords naturally.
- Communicate the page's value clearly.
- Avoid duplicate descriptions across pages.

## 5.3 Canonical Tags

Canonical tags identify the preferred URL for a webpage and help prevent duplicate URL indexing issues.

Example:

`<link rel="canonical" href="https://zydntechpark.in/" />`

Each indexable page should have a self-referencing canonical URL unless another canonical destination is intentionally selected.

## 5.4 Robots Meta Tags

Robots directives communicate indexing and crawling preferences to search engines.

Example:

`<meta name="robots" content="index, follow">`

Important public pages should be indexable unless there is a specific reason to restrict them.

## 5.5 Heading Structure

The website should follow a logical heading hierarchy:

- H1: Main page heading
- H2: Main content sections
- H3: Subsections
- H4: Supporting subsections

Each page should have a clear primary heading and a meaningful content hierarchy.

## 5.6 Image Optimization

Image optimization improves page loading speed and accessibility.

Implementation requirements:

- Descriptive image file names
- Relevant ALT attributes
- Compressed image formats
- Appropriate image dimensions
- Responsive images
- Lazy loading for below-the-fold images

- Be submitted through Google Search Console and Bing Webmaster Tools.

## 9.2 Robots.txt

The robots.txt file provides crawling instructions to search engine bots.

Recommended location:

`https://zydntechpark.in/robots.txt`

The file should allow access to important public website content and reference the XML sitemap.

Example:

`Allow: /`
